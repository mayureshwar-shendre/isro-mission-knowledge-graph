</div>

---


## 🧠 Overview

The RAG (Retrieval-Augmented Generation) + Semantic Search Layer enables intelligent querying over the ISRO Knowledge Graph by combining embeddings, vector databases, and LLM-powered contextual retrieval.

---


## 🎯 Purpose

To allow users to ask natural language questions like:
~~~
“Which rocket launched the most ISRO satellites?”
and receive accurate, context-aware answers from the knowledge graph.
~~~

---


## ⚙️ Key Responsibilities

1. Embedding generation from mission data

2. Vector indexing (FAISS / Pinecone)

3. Semantic similarity search

4. Context-aware Q&A using RAG pipelines
 
---


## 🔍 Capabilities

1. Natural Language Querying

2. Contextual Knowledge Retrieval

3. Intelligent Mission Insights

4. Multi-hop reasoning across graph

---


## 📊 Input

1. Knowledge Graph + Documents

2. User Queries

---


## 📤 Output

1. Contextual Answers

2. Retrieved Knowledge Chunks
